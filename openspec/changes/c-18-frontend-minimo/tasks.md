- [ ] 3.3 Implementar en `frontend/src/app.ts` la vista de **Agenda de un profesional** (`GET /agenda/profesionales/{id}?desde=&hasta=`): carga de catálogo `GET /profesionales`, `GET /sillones`, `GET /prestaciones` y (solo para `administracion`/`recepcion`) `GET /pacientes` (`RN-PAC-03`); renderizado de turnos `reservado` y bloqueos en orden cronológico, estado vacío cuando `items = []`, visualización de `"Paciente #<paciente_id>"` para `odontologo`, y alerta con el `mensaje` en español cuando un `odontologo` consulta otro profesional y recibe `403 sin_permiso` (`RN-ACC-03`).
