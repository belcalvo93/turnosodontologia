# Wati (turnos clínicos por WhatsApp)

- **URL**: https://www.wati.io/geo-argentina-es/automatiza-los-turnos-clinicos-por-whatsapp-sin-perder-el-cont
- **Fecha de investigación**: 2026-10-08

## Problema que resuelve

"Un turno sin confirmar deja un hueco en la agenda y obliga a recepción a repetir el mismo trabajo"; además, contestar desde teléfonos personales no deja trazabilidad.

## Usuarios objetivo

Clínicas (ejemplo: clínica odontológica de Buenos Aires): recepción, coordinación y pacientes.

## Features detectadas

- Plantillas de confirmación, recordatorio y aviso de cambio de turno
- Recordatorio 48 h antes con botones "confirmar" / "cambiar"
- Chatbot sin código para preguntas frecuentes
- Bandeja compartida del equipo con historial
- Flujos por especialidad, profesional o sede
- Seguimientos post-atención

## Pricing

(no publicado) en la página. Aclara que la API de WhatsApp tiene costos de Meta además de la plataforma.

## Posicionamiento

Canal de ventas y soporte automatizado con IA, 24 h.

## Diferenciadores

BSP oficial de Meta, +16.000 empresas, GDPR y SOC 2.

## Notas del investigador

No es un sistema de turnos: es la capa de mensajería. No sincroniza automáticamente con la agenda. Muestra que el dolor real es la no confirmación / ausentismo, y que WhatsApp con API oficial tiene costo por mensaje.
