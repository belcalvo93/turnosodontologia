Usé la IA como guía paso a paso para instalar el Active Stack, resolver los problemas de git (el error 403, las ramas y el PR) y entender cada etapa del apply. El agente escribió el código con Strict TDD, pero yo aprobé cada permiso y cada commit.

El agente escribió el código y los tests; yo revisé cada checkpoint, hice los commits y abrí los PR.

Para C-18, Claude escribió el código de las tareas 3.4, 3.5 y 4.5 y de los ajustes que pidió Belén, lo probó en un navegador automático contra la API con el seed demo y me lo pasó como commits a mi nombre. Yo los apliqué y los subí con git, abrí los PR e hice a mano la prueba del rol odontólogo y la del README desde cero. También usé Claude para revisar el PR #71 de Bruno antes de aprobarlo.
